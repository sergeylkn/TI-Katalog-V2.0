# Техническое задание для Stitch
## Мобильное приложение для тренировок с гирей и без снаряда

---

## 1. Концепция

**Название (рабочее):** Kettle&Body / «Гиря и Тело»

**Суть:** мобильный тренировочный помощник с каталогом упражнений с гирей
(базовый вес **24 кг**, переключаемый на **16 кг** или **32 кг**) и упражнений
с собственным весом. Каждое упражнение сгруппировано по группе мышц, содержит
**GIF-анимацию правильной техники** и **схему задействованных мышц**.

**Целевой пользователь:** мужчины и женщины 20–45 лет, тренирующиеся дома или
в зале, от новичка до продвинутого.

**Ключевая ценность:** быстро найти эффективное упражнение, увидеть, как его
выполнять правильно, и понять, какие мышцы оно нагружает.

## 2. Дизайн-система

| Параметр | Значение |
|---|---|
| Тема | Тёмная (основной режим), опционально светлая |
| Фон | Глубокий графит `#0E0F13`, карточки `#181A20` |
| Акцент | Энергичный оранжевый `#FF6B35` (гиря), синий `#3DA9FC` (без снаряда) |
| Текст | Белый `#FFFFFF`, вторичный серый `#9AA0AC` |
| Успех/мышцы | Зелёный `#4CD964` |
| Шрифт | Гротеск, крупные жирные заголовки, читаемый body |
| Скругления | 16–20 px, мягкие карточки |
| Иконки | Линейные, минималистичные |
| Стиль | Современный, чистый, много «воздуха», крупные тапабельные зоны |

**Настроение:** спортивное, премиальное, мотивирующее. Не перегруженное.
Ориентир — уровень Nike Training Club / Freeletics по аккуратности.

## 3. Структура данных упражнения

Каждое упражнение — карточка со следующими полями:

```
Упражнение {
  название            // "Махи гирей"
  тип                 // "Гиря" | "Без снаряда"
  группа_мышц         // Ноги/Ягодицы, Спина, Грудь/Плечи, Руки, Кор, Всё тело
  уровень             // Новичок | Средний | Продвинутый
  вес (для гири)      // выбор: 16 / 24 / 32 кг  (по умолчанию 24)
  gif_техники         // анимация правильного выполнения
  схема_мышц          // изображение тела с подсветкой работающих мышц
  основные_мышцы      // список (для подписи под схемой)
  описание_техники    // пошаговый текст: исходное положение → движение → ошибки
  подходы_повторы     // рекомендация, напр. "4×15" или "40 сек"
}
```

**Важно (переключатель веса):** на экране упражнения с гирей — сегментированный
переключатель **16 / 24 / 32 кг**. При смене веса обновляется рекомендация по
повторам (легче вес → больше повторов) и, при наличии, подпись сложности.

## 4. Экраны приложения

### 4.1. Главный экран (Home)
- Приветствие + мотивационная строка дня.
- Крупная карточка «Тренировка дня» с кнопкой **Старт**.
- Быстрые фильтры-чипсы: `Гиря` · `Без снаряда` · по группам мышц.
- Горизонтальные подборки: «Популярное», «Для начинающих», «Кор за 10 минут».
- Внизу — таб-бар: **Дом · Каталог · Тренировка · Профиль**.

### 4.2. Каталог упражнений (Exercises)
- Верхний переключатель: **Гиря / Без снаряда / Все**.
- Список групп мышц секциями (аккордеон или карточки):
  Ноги/Ягодицы · Спина · Грудь/Плечи · Руки · Кор · Всё тело.
- Каждая карточка упражнения: превью-GIF (или иконка), название, бейдж группы
  мышц, бейдж уровня, бейдж веса для гири.
- Поиск сверху + фильтры (уровень, тип, группа мышц).

### 4.3. Экран упражнения (Exercise Detail) — ключевой
Сверху вниз:
1. Крупное название + бейджи (группа мышц, уровень).
2. **GIF правильной техники** (большой блок, автоплей, зацикленный).
3. Для гири — **сегментированный переключатель веса 16 / 24 / 32 кг**.
4. **Схема мышц** — силуэт тела с подсвеченными работающими мышцами +
   подпись «Основные мышцы: …».
5. Блок **«Техника»** — пошаговое описание (Исходное положение → Выполнение →
   Дыхание → Частые ошибки).
6. Рекомендация: подходы × повторы (меняется от выбранного веса).
7. Кнопки: **Добавить в тренировку**, **Начать таймер**.

### 4.4. Экран тренировки (Workout Player)
- Крупный таймер, название текущего упражнения, GIF, прогресс «упражнение X из N».
- Кнопки **Старт / Пауза / Далее**, фаза «Работа / Отдых».
- (Опционально) голосовые подсказки и вибрация на смене упражнения.

### 4.5. Профиль (Profile)
- Статистика: тренировки за неделю, суммарное время, любимые упражнения.
- Настройки: тема, вес гири по умолчанию, единицы, звук/вибрация.

## 6. Требования к контенту карточки
- **GIF техники** — вид сбоку, 2–4 секунды, зациклен, чистый фон.
- **Схема мышц** — силуэт тела (перед/спина), работающие мышцы подсвечены
  акцентным цветом; целевые — ярче, вспомогательные — бледнее.
- **Текст техники** — 4 коротких блока: *Исходное положение*, *Выполнение*,
  *Дыхание*, *Частые ошибки*. Короткие фразы, без «воды».

## 9. Анализ конкурентов и что мы берём лучшее (v2)

| Приложение | Сильная сторона | Что берём |
|---|---|---|
| **Fitbod** | Тепловая карта восстановления мышц | Экран Progress: анатомическая фигура-«heatmap» восстановления («Ягодицы 45% — отдых 1 день») |
| **Nike Training Club** | Премиальный арт-дирекшн, крупная типографика | Massive-заголовки, чистые тёмные экраны, коллекции подборок |
| **Freeletics** | Недельный план + streak-мотивация | Экран Weekly Plan, огонёк-streak на главном, achievement-тосты |
| **Hevy / Strong** | Личные рекорды и объём (kg volume) | Карточки PR и «Volume 2 340 kg» на Workout Complete |
| **Muscle Booster** | Анатомическая визуализация мышц | Реалистичные écorché-фигуры (перед+спина) с градацией Primary / Secondary / Stabilizer |
| **Centr** | Дружелюбный онбординг с целями | Экран Onboarding: цель, уровень, какие гири есть |

**Чем будем лучше:** ни одно из них не совмещает (1) реалистичную анатомию с
градацией интенсивности, (2) восстановление мышц, (3) недельный план под гири
16/24/32 и (4) голосовой таймер — у нас всё это в одном приложении.
